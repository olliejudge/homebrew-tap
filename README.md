# Ollie's Homebrew tap

## DS Mac Tools

A controller workbench for Mac game developers: live inputs, test recordings, feedback presets, development diagnostics and DualSense firmware updates.

```sh
brew tap olliejudge/tap
brew install dsmactools
dsmactools
```

Or install directly with `brew install olliejudge/tap/dsmactools`.

[Project and documentation](https://github.com/olliejudge/dsmactools)

## Orion

A live map of your Git repository across worktrees.

```sh
brew install --cask olliejudge/tap/orion
```

[Project and documentation](https://github.com/olliejudge/orion)

## Updates

```sh
brew update
brew upgrade
```

Each package has its own formula or cask and is installed independently.
